# Un ratito juntos ❤️

Un pequeño juego de preguntas creado por Biel con mucho cariño para sus abuelos, Joaquín y Josefa.

## Cómo jugar
- Abre la página web desde el móvil, una tablet o un ordenador.
- Pulsa **¡Vamos a jugar!**
- Leed cada pregunta y elegid una de las tres respuestas.
- No hay límite de tiempo ni penalizaciones: podéis jugar juntos y ayudaros.
- Cada partida selecciona 10 preguntas de una colección de cultura general sencilla.

## Publicación
Es una web estática: no necesita instalar nada, servidor, base de datos ni dependencias externas.

Para publicarla con GitHub Pages:
1. En el repositorio, abre **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige la rama **main** y la carpeta **/(root)**, y guarda.

La página quedará disponible en `https://bvilla2011-cyber.github.io/SpicyQuiz/` cuando Pages termine de publicarla.

Hecho con ❤️ por Biel.
